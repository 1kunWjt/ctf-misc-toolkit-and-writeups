# AFCTF · Vigenère 题解

## 一、仓库地址先纠个错

| 你给的 | 结果 |
| --- | --- |
| `https://github.com/atomcated/VigenereYzyj` | **404**（该仓库不存在；用户 `atomcated` 存在，但只有 1 个公开仓库） |
| `https://github.com/atomcated/Vigenere` | ✅ 真身：`维吉尼亚密码加密解密程序，包含自动猜测密钥功能`，JavaScript，2015-07，43 ★ |

**关键发现**：`VigenereYzyj` 里的 `Yzyj` 不是仓库名的一部分，而是**密文开头的 4 个字母**。
把它接回密文前面，明文才完整地从 `When in the Course of human events...` 开始（少这 4 个字母，"When" 丢了，而且 key 会对齐错位）。
所以复制的时候，密文第一个词被粘到 URL 后面了——这也正好是判断 key 对齐的线索。

## 二、这个仓库干了什么

只有三个文件：`index.html`（界面）、`js/demo.js`（算法）、`README.md`（就一行标题）。

界面：明文框 / 密文框 / 密钥输入 / 三个按钮（加密、有密钥解密、无密钥解密）+ 一个「key 长度」输入框。

`js/demo.js` 的三个核心：

1. `Vigenere(strIn, key, encode)` —— 标准维吉尼亚：
   - 只处理 `a-zA-Z`，其它字符原样输出且**不消耗 key**（这点最容易写错）；
   - 大小写保持，`key` 统一转小写。
2. `deVigenereAuto()` 猜密钥长度：
   ```js
   for (best_len = 3; best_len < 13; best_len++) {   // 只试 3~12
       // 每一列算重合指数 IC，再取平均
       if (sum / best_len > 0.065) break;            // 第一次超过 0.065 就停
   }
   ```
3. `deVigenereAuto()` 猜密钥：每列枚举 26 个位移，用英文字母频率点乘取最大
   ```js
   cur_dp += freq[k] * count[(k + i) % 26];
   ```

结论：**就是教科书维吉尼亚，没有变体**。它的价值在于「自动猜长度 + 猜密钥」，适合快速试。

## 三、本题结果

| 项 | 值 |
| --- | --- |
| 密钥长度 | **12** |
| 密钥 | **`csuwangjiang`**（按明文首字母 `W` 对齐） |
| 明文 | 美国《独立宣言》（The Declaration of Independence），中段被塞了一行 flag |
| flag | **`afctf{Whooooooo_U_Gotcha!}`** |

IC（重合指数）实测，长度 12 明显是峰：

```
 L= 4  0.0482     L= 8  0.0488
 L= 6  0.0547     L=12  0.0702   <== 峰（英文约 0.0667，随机约 0.0385）
```

因为维吉尼亚是**周期性**替换，密钥整体旋转等价：
从密文首词 `Yzyj` 起算得到 `csuwangjiang`；如果从 `ia` 起算就是 `angjiangcsuw`——两者解出来只差开头的 `When`，flag 完全一样。

**校验**：用密钥把明文重新加密，与密文逐字母比对 **6554/6554 完全一致（0 处不同）**，说明密钥是精确的，不是"看着像"。

## 四、怎么复现

**方式 A：用原仓库**
1. 打开 `index.html`（或 <https://atomcated.github.io/Vigenere>）；
2. 密文粘进右边「密文」框（记得带上开头的 `Yzyj`）；
3. 「key 长度」填 `12`，点「无密钥解密」；
4. 页面下方会显示「最可能的密钥：csuwangjiang」，左边出现明文。

> 注意：仓库的自动猜长度**只试 3~12**，本题刚好 12 能中；要是题目 key 更长（比如 15），它会漏掉，需要把 `best_len < 13` 改大。

**方式 B：本目录的脚本**
```bat
node 工具\vig_solve.js
```
会扫 1~30 全部长度，打印 IC 表、每种的英文评分、最优密钥、明文前 600 字和 flag。

## 五、下次遇到维吉尼亚的套路

1. **判长度**：算各长度的平均 IC，找**峰**（而不是"第一次超过阈值"），峰一般落在真实周期的整数倍上。
2. **恢复密钥**：每列做频率匹配（点乘）或 χ²；样本 ≥ 500 字母才靠谱，太短就靠 crib（已知明文）猜。
3. **对齐**：维吉尼亚只在字母上推进 key，标点/空格/换行不占位。开头少几个字母整段就废——本题的 `Yzyj` 就是这样的线索。
4. 有已知明文片段时（flag 格式 `afctf{`），可以直接用它反推周期性 key 片段，比纯统计更稳。
