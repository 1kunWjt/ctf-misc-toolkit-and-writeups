# 正则库 · 换题目只改一行

配合 `tpl.py` + `tpl.bat` 使用。**所有正则都在下面标了实测结果**，可以放心直接抄。

---

## 0. 怎么用（30 秒）

1. 用记事本 / VSCode 打开 `tpl.py`，只看**第 12 行**：

   ```python
   REGEX      = r"\{(.*?)\}"   # ← 从《正则库.md》抄一条粘过来
   ```

2. 把新正则**整个替换**到等号右边（保留 `r"..."` 的写法）。
3. 保存 → 把题目文件**拖到 `tpl.bat` 上** → 看最后一行输出。

> 只改 `REGEX` 一行就能应付 80% 的题；剩下 20% 改第 13~19 行的开关。

---

## 1. 先看文件长什么样 → 粘这条

打开题目文件瞄一眼（记事本/CyberChef 都行），对照下表：

| 你在文件里看到 | 粘进 `REGEX` 的写法 | 实测抽到的内容 |
|---|---|---|
| `flag{abc}` `{d}{e}` | `r"\{(.*?)\}"` | `abc`、`d`、`e` |
| `[xy]` `[ab]` | `r"\[(.*?)\]"` | `xy`、`ab` |
| `(uv)` `(cd)` | `r"\((.*?)\)"` | `uv`、`cd` |
| `"pq"` `"rs"` | `r'"(.*?)"'` | `pq`、`rs` |
| `'pq'` `'rs'` | `r"'(.*?)'"` | `pq`、`rs` |
| `<tag>` `</a>` | `r"<(.*?)>"` | `tag`、`/a` |
| `《书名》` | `r"《(.*?)》"` | `书名` |
| `“中文引号”` | `r"“(.*?)”"` | `中文引号` |
| `【方头】` | `r"【(.*?)】"` | `方头` |
| `{}` 和 `[]` **混着出现** | `r"[{\[](.*?)[}\]]"` | `abc`、`xy` |
| 只想要 `flag{...}` 里的东西 | `r"flag\{(.*?)\}"` | `abc` |
| **一行就是一段**，没有括号 | `r"^\s*(.+?)\s*$"` | 每一行（自动去了首尾空格） |
| 一堆英文单词 | `r"[A-Za-z]+"` | `hello`、`World`、`flag` |
| 英文字母+数字+下划线串 | `r"[A-Za-z0-9_]+"` | `World_flag`、`aGVsbG8` |
| 一堆数字 | `r"\d+"` | `2024`、`0721`、`42` |
| 十六进制串 | `r"[0-9a-fA-F]{4,}"` | `deadbeef`、`01011010` |
| 8 位二进制 | `r"[01]{8}"` | `01011010` |
| JSON 里的值 | `r':\s*"(.*?)"'` | `value` |
| `%41` 这种 URL 编码 | `r"%([0-9A-Fa-f]{2})"` | `41` |
| `&#65;` 这种 HTML 实体 | `r"&#(\d+);"` | `65` |
| `\x41` 这种转义 | `r"\\x([0-9a-fA-F]{2})"` | `41`、`42` |
| 每 3 个字一组 | `r"(.{3})"` | `fla`、`g{a`、`bc}` |
| 疑似 base64 | `r"[A-Za-z0-9+/]{8,}={0,2}"` | `aGVsbG8gd29ybGQ=` |
| IP 地址 | `r"(?:\d{1,3}\.){3}\d{1,3}"` | `192.168.1.1` |
| URL | `r"https?://[^\s]+"` | `https://example.com/path?x=1` |
| 完全看不出来结构 | `""`（留空） | 整个文件逐字符统计 |

## 2. 正则库大全

### 2.1 括号 / 引号类

| 用途 | 正则 | 实测 |
|---|---|---|
| 花括号 | `r"\{(.*?)\}"` | `['abc', '"key": "value"']` |
| 方括号 | `r"\[(.*?)\]"` | `['xy']` |
| 圆括号 | `r"\((.*?)\)"` | `['uv']` |
| 尖括号 | `r"<(.*?)>"` | `['tag', 'a href="http://x.com/a"', '/a']` |
| 书名号 | `r"《(.*?)》"` | `['书名']` |
| 中文引号 | `r"“([^”]*)”"` | `['中文引号']` |
| 方头括号 | `r"【(.*?)】"` | `['方头']` |
| 双引号 | `r'"(.*?)"'` | `['pq', 'key', 'value', 'num', 'http://x.com/a']` |
| 单引号 | `r"'(.*?)'"` | `['rs']` |
| 花括号+方括号混用 | `r"[{\[](.*?)[}\]]"` | `['abc', 'xy']` |
| 只要 `flag{}` 内层 | `r"flag\{(.*?)\}"` | `['abc']` |
| 零宽断言版（结果里不含括号本身） | `r"(?<=\{)(.*?)(?=\})"` | `['abc']` |

### 2.2 字符类

| 用途 | 正则 | 实测 |
|---|---|---|
| 英文单词 | `r"[A-Za-z]+"` | `['flag','abc','xy',...]` |
| 字母数字下划线串 | `r"[A-Za-z0-9_]+"` | `['flag','abc','2024','deadbeef',...]` |
| 数字串 | `r"\d+"` | `['2024','0721','01011010','3','14','42']` |
| 4 位以上十六进制 | `r"[0-9a-fA-F]{4,}"` | `['2024','0721','deadbeef','01011010','AAAA']` |
| 8 位二进制 | `r"[01]{8}"` | `['01011010']` |
| 非空白连续串（最宽松，兜底用） | `r"[^\s]+"` | `['flag{abc}','[xy]','(uv)',...]` |
| `\w+`（含中文！） | `r"\w+"` | `['flag','书名','中文引号','方头',...]` |
| 只取 ASCII 可见字符（中文会被跳过） | `r"[\x20-\x7e]"` | 每个可见 ASCII 一个 |
| 汉字 | `r"[\u4e00-\u9fa5]+"` | `['书名','中文引号','方头','链接']` |

### 2.3 结构类

| 用途 | 正则 | 实测 |
|---|---|---|
| JSON 的值 | `r':\s*"(.*?)"'` | `['value']` |
| URL 编码 `%XX` | `r"%([0-9A-Fa-f]{2})"` | `['41']` |
| HTML 实体 `&#NN;` | `r"&#(\d+);"` | `['65']` |
| 转义十六进制 `\xNN` | `r"\\x([0-9a-fA-F]{2})"` | `['41','42']` |
| URL | `r"https?://[^\s]+"` | `['https://example.com/path?x=1']` |
| IP（注意非捕获组） | `r"(?:\d{1,3}\.){3}\d{1,3}"` | `['192.168.1.1']` |
| base64 候选 | `r"[A-Za-z0-9+/]{8,}={0,2}"` | `['aGVsbG8gd29ybGQ=']` |
| 时间 `12:34:56` | `r"\d{1,2}:\d{2}:\d{2}"` | `['12:34:56']` |
| 日期 `2024-07-21` | `r"\d{4}-\d{2}-\d{2}"` | `['2024-07-21']` |
| 邮箱 | `r"[\w.+-]+@[\w-]+\.[\w.]+"` | `['a@b.com']` |

### 2.4 分组类（把长串切成小段）

| 用途 | 正则 | 实测 |
|---|---|---|
| 每 2 个字符一组 | `r"(.{2})"` | `['fl','ag','{a','bc',...]` |
| 每 3 个字符一组 | `r"(.{3})"` | `['fla','g{a','bc}',...]` |
| 每 4 个字符一组 | `r"(.{4})"` | `['flag','{abc',...]` |
| 用逗号/空格分隔的每一段 | `r"[^,\s]+"` | `['a','b','c']` |
| 按竖线分隔 | `r"[^|]+"` | `['a','b','c']` |

## 3. 不用改正则，改开关就行

| 需求 | 改哪行 | 怎么改 |
|---|---|---|
| 整个文件都统计，不要抽取 | `REGEX` | `REGEX = ""` |
| 区分大小写 | `LOWER` | `False` |
| 保留空格换行 | `DROP_SPACE` | `False` |
| 只统计十六进制字符 | `KEEP` | `"0123456789abcdef"` |
| 只统计数字 | `KEEP` | `"0123456789"` |
| 从少到多 | `ORDER` | `"asc"` |
| 只显示前 10 名 | `TOP` | `10` |
| 自动包成 `flag{...}` | `WRAP` | `"flag{%s}"` |
| 抓不到东西，想看抓了啥 | `SHOW` | `5` |
| 不想生成报告文件 | `SAVE` | `False` |

> `KEEP` 是**区分大小写**的，而且过滤发生在转小写之前。
> 所以要过滤大写字母时，写全 `"0123456789abcdefABCDEF"`，或者先 `LOWER = False`。

## 4. 输出是空的 / 结果不对？按这 6 步排查

| 步骤 | 做什么 | 说明 |
|---|---|---|
| ① | `REGEX = ""` 再跑一次 | 能出结果 → 是正则没匹配上；还是空 → 文件读错了 |
| ② | `SHOW = 5` 再跑一次 | 直接看抽出来的前 5 段长什么样，一眼看出对不对 |
| ③ | 打开文件看第 1 行 | 有可能根本不是 `{}`，是 `[]`、`【】`、`<>` |
| ④ | 检查转义 | `{ } [ ] ( ) . * + ?` 这些**前面都要加** `\` |
| ⑤ | 换宽松正则试 | 用 `r"[^\s]+"` 或 `r"."`，能匹配就说明思路对，再收紧 |
| ⑥ | 换编码 | 乱码/问号方块 → 文件是 GBK，模板会自动试，但如果原文是 UTF-16 就会失败 |

## 5. 多捕获组的坑（考试最容易翻车的地方）

### 现象

`findall` 返回的不是字符串，而是**元组**，拼接时报 `TypeError`，或者统计结果乱七八糟。

### 原因

正则里**有几个 `( )`，findall 就返回几元组**。

### 实测对比

```python
# ✗ 错：两个捕获组 → 返回元组，还夹着空串
re.findall(r"\{(.*?)\}|\[(.*?)\]", "flag{abc} [xy]", re.S)
#   → [('abc', ''), ('', 'xy')]

# ✓ 对：只留一个组，用字符类表示"左括号"/"右括号"
re.findall(r"[{\[](.*?)[}\]]", "flag{abc} [xy]", re.S)
#   → ['abc', 'xy']
```

```python
# ✗ 错：IP 写成了重复捕获组，只会拿到最后一个 "1."
re.findall(r"(\d{1,3}\.){3}\d{1,3}", "192.168.1.1")
#   → ['1.']

# ✓ 对：内层改成非捕获组 (?:...)
re.findall(r"(?:\d{1,3}\.){3}\d{1,3}", "192.168.1.1")
#   → ['192.168.1.1']
```

### 两种修法

1. **内层括号加 `?:`**：`(?:...)` —— 只分组，不捕获。
2. **整体只留一个捕获组**，其余用字符类 `[...]` 代替。

> `tpl.py` 检测到元组时会打印提示，并临时取每组的第 1 个元素。
> 但**别指望它自动修好**，还是自己把正则写对。

## 6. 转义速查（这几行抄在草稿纸上）

| 字符 | 转义写法 | 出现在正则里的意思 |
|---|---|---|
| `{` `}` | `\{` `\}` | 字面花括号 |
| `[` `]` | `\[` `\]` | 字面方括号 |
| `(` `)` | `\(` `\)` | 字面圆括号（不转义 = 捕获组） |
| `.` | `\.` | 字面点（不转义 = 任意字符） |
| `*` `+` `?` | `\*` `\+` `\?` | 字面符号（不转义 = 量词） |
| `^` `$` | `\^` `\$` | 行首/行尾 |
| `\|` | `\\|` | 字面竖线（不转义 = 或） |
| `\` | `\\` | 字面反斜杠 |

**记不住就一条：不确定的字符，前面统统加 `\`。** 加错了顶多不匹配，不会把别的匹配搞坏。

## 7. 配置项全表（`tpl.py` 第 12~20 行）

```python
REGEX      = r"\{(.*?)\}"   # 抽取规则，留空 "" = 整个文件
LOWER      = True           # 是否统一转小写
DROP_SPACE = True           # 是否删掉空格换行
KEEP       = ""             # 只保留这些字符，如 "0123456789abcdef"
ORDER      = "desc"         # desc=从多到少 / asc=从少到多
TOP        = 0              # 0=全部；10=只显示前 10
WRAP       = ""             # "flag{%s}" 自动包格式
SHOW       = 0              # >0 打印前 N 段抽取结果（排查用）
SAVE       = True           # 是否生成 *-词频.txt
```

## 8. 常见题型 → 配方（一页速查）

| 题型 | 配方 |
|---|---|
| `{}` 里藏字符，按频率排序（NSS 我flag呢？这类） | `r"\{(.*?)\}"` + 默认配置 |
| 一堆 `[x]` 形式的碎片 | `r"\[(.*?)\]"` |
| 每行末尾藏一个字符 | `r"^\s*(.+?)\s*$"`（取整行）+ `KEEP` 过滤 |
| 给你一段英文、要单词频率 | `r"[A-Za-z]+"`，`LOWER=True` |
| 给你一串 hex | `r"[0-9a-fA-F]+"` + `KEEP="0123456789abcdef"` |
| 给你 base64 | `r"[A-Za-z0-9+/]{8,}={0,2}"`，抽出来再 `base64.b64decode` |
| 给你 URL 编码串 | `r"%([0-9A-Fa-f]{2})"`，拿到 hex 再 `bytes.fromhex` |
| 给你一串 01 | `REGEX=""`，`KEEP="01"` |
| 完全不知道结构 | `REGEX=""`，先跑一遍看字符分布，再决定 |
| 抽取窗口对不上 | `SHOW=5` 看抽了啥，再改 `REGEX` |

---

## 9. 还是不对？两个动作

1. 把 `REGEX` 换成 `r"."`（任何一个字符都匹配）跑一遍：
   - 有输出 → 说明是**正则写错**，回到第 1 节对照
   - 没输出 → 说明是**文件读错**，用记事本打开确认它到底是不是文本文件（不是的话这题就不是词频）
2. 把 `SHOW` 改成 `10`，把抽出来的东西跟文件原文逐段比对，一定能看出差在哪。
