## 二、每类文件的"第一动作"

| 拿到什么 | 第一动作 | 命令 / 工具 |
|---|---|---|
| 陌生文件 | 看魔数 + `file` 语义 | `Format-Hex -Count 16 x.bin` |
| PNG | 验 8 字节魔数 → 读 IHDR（宽高）→ 算 CRC | 见 [09 篇](../03-Misc-图片与隐写/09-为什么我什么都看不见.md) |
| JPG | 看尾部是否追加了 ZIP | `Format-Hex -Tail`，或 `binwalk`（补齐包里） |
| GIF | 数帧 → 逐帧扫 → 拼 | Pillow `ImageSequence` |
| ZIP | 先看是否伪加密 / 明文攻击 / 弱口令 | `bkcrack`（`D:\DSH\bkcrack一键`） |
| PDF | 扫 `/Encrypt`，看 `V/R/CFM` 判 RC4 还是 AES | `misc\pdf_analyze.bat` |
| pcap/pcapng | 统计 → 协议分级，找"不该存在"的协议 | `tshark -q -z io,phs` |
| 一堆碎片图 | 数纯色边 → 定网格 | 拼图还原器 |
| 一段乱码 | CyberChef Magic | 本地版 CyberChef |
| 需要"逐字符码值偏移" | ASCII 偏移小工具 | `Ctrl+Alt+M` 调码表 |

## 三、常用一行命令（PowerShell）

```powershell
# 看文件头 16 字节
Format-Hex -Path .\a.bin -Count 16

# 全量 strings（等效）
Select-String -Path .\a.bin -Pattern '[\x20-\x7e]{6,}' -AllMatches |
  ForEach-Object { $_.Matches.Value } | Select-Object -Unique

# tshark 常用三连
& "D:\Program Files\Wireshark\tshark.exe" -r a.pcapng -q -z io,phs        # 协议分级
& "D:\Program Files\Wireshark\tshark.exe" -r a.pcapng -Y http -T fields -e http.request.uri
& "D:\Program Files\Wireshark\tshark.exe" -r a.pcapng --export-objects http,.\out

# Python 做事前先定编码，避免中文乱码
$env:PYTHONIOENCODING = "utf-8"
& "C:\Users\XiaoMibook\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" .\solve.py
```

## 四、比赛节奏（省赛 4 小时经验）

| 时段 | 做什么 |

## 五、写 WP 的自检（赛后 20 分钟）

1. flag 有没有原样贴（含大小写、花括号）
2. "为什么这么做"有没有写——只贴命令的 WP 一周后自己都看不懂
3. 踩过的坑有没有记——那是最值钱的部分
4. 脚本能不能重跑（路径写死没有）
