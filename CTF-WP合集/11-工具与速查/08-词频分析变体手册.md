# 考场变体手册：词频分析怎么改

核心只有 5 步，任何变体都只改其中**一步**：

```
读文件  →  抽取/清洗出字符串 s  →  Counter 排序  →  输出
 ①            ②                    ③              ④
```

配套文件：
- `03_学原理_搞懂它/考场速写版.py` —— 15 行，闭卷能默写的那份
- `04_变体参考/变体片段.py` —— 每个变体一个函数，跑 `python 变体片段.py` 看效果

## 一、默写模板（考场直接抄）

```python
import sys, re
from collections import Counter

path = sys.argv[1] if len(sys.argv) > 1 else 'flag.txt'
text = open(path, 'rb').read().decode('utf-8', errors='ignore')   # ①

items = re.findall(r'\{(.*?)\}', text, re.S)                      # ②
s = ''.join(items)
s = ''.join(s.split())                                            # 去空白

rank = Counter(s.lower()).most_common()                           # ③

print(' '.join('%s:%d' % (c, n) for c, n in rank))                # ④ 自查
print(''.join(c for c, _ in rank))                                # ④ 答案
```

**记忆口诀：** `rb+decode` 不崩、`findall` 抓括号、`split` 去空白、
`Counter.most_common` 排序、`join` 拼串。

## 二、决策表：题目怎么说 → 改哪一行

| 题目里的说法 | 改动 | 代码 |
|---|---|---|
| “每个 flag 字符在 `{}` 里” | 不动 | `r'\{(.*?)\}'` |
| “在 `[]` 里 / `()` 里 / 引号里” | 改正则 | `r'\[(.*?)\]'` / `r'\((.*?)\)'` / `r'"(.*?)"'` |
| “片段可能跨多行” | 加 `re.S` | 已经是 `re.S`，别删 |
| “整份文件就是密文，没有括号” | 不要 findall | `s = text` |
| “忽略大小写 / 全部转小写” | 用 `.lower()` | `Counter(s.lower())` |
| “区分大小写” | 去掉 `.lower()` | `Counter(s)` |
| “忽略空格和换行” | 保留 `split()` | `s = ''.join(s.split())` |
| “只统计字母 / 只统计十六进制” | 加过滤 | `[c for c in s if c.isalnum()]` |
| “按出现次数**从多到少**” | 默认 | `most_common()` |
| “按出现次数**从少到多**” | 反转 | `most_common()[::-1]` |
| “输出字符**和**次数” | 直接打印元组 | `print(Counter(s).most_common())` |
| “次数相同的按首次出现顺序” | 默认就是 | 不用改 |
| “次数相同的按 ASCII 排” | 加 key | `sorted(cnt.items(), key=lambda kv: (-kv[1], kv[0]))` |
| “只要出现次数最多的那个字符” | 取第一个 | `Counter(s).most_common(1)[0][0]` |
| “结果替换回 flag 格式” | 加外壳 | `'flag{%s}' % body` |
| “输出用 `_` 连接” | 改 join | `'_'.join(...)` |
| “统计**两个**字符的组合” | 切片 | `Counter(s[i:i+2] for i in range(len(s)-1))` |
| “统计**单词**频率” | 改正则 | `Counter(re.findall(r'[A-Za-z]+', text.lower()))` |
| “文件是 GBK / 打不开” | 换 decode | `open(path,'rb').read().decode('gbk','ignore')` |
| “要每个字符出现的位置” | 枚举 | `{ch: [i for i,c in enumerate(s) if c==ch]}` |

## 三、变体代码速查（都实测跑过）

### 1. 括号换了 —— 只改正则

```python
r'\{(.*?)\}'     # 花括号
r'\[(.*?)\]'     # 方括号
r'\((.*?)\)'     # 圆括号
r'"(.*?)"'       # 双引号
r'<(.*?)>'       # 尖括号
r'\{(.*?)\}'     # 只有一处时也能用 text.split('{')[1].split('}')[0]
```

> 正则里 `{ } [ ] ( )` 是元字符，**必须转义**，这是最常见的扣分点。
> 实测：`a[ab]b(cd)c"ef"d<gh>e` → `{'square':'ab','round':'cd','quasi':'ef','angle':'gh'}`

### 2. 没有括号，整份文件

```python
s = text
# 或直接：''.join(c for c, _ in Counter(text).most_common())
```

### 3. 去空白 / 只留某个字符集

```python
s = ''.join(s.split())                          # 去掉所有空白（推荐）
s = re.sub(r'\s+', '', s)                       # 等价写法
s = ''.join(c for c in s if c.isalnum())        # 只留字母数字
s = ''.join(c for c in s if c in '0123456789abcdef')   # 自定义字符集
```

### 4. 大小写

```python
Counter(s.lower())   # 不区分
Counter(s)           # 区分
```

### 5. 升序 / 只取前 N

```python
Counter(s).most_common()[::-1]      # 从少到多
Counter(s).most_common(10)          # 只要前 10 种
```

### 6. 要表格（字符 + 次数）

```python
for ch, n in Counter(s).most_common():
    print(repr(ch), n)      # repr 能看出空格/换行，别直接 print
```

### 7. 并列怎么排

```python
cnt = Counter(s)
''.join(c for c, _ in cnt.most_common())                                  # 并列按首次出现
''.join(c for c, _ in sorted(cnt.items(), key=lambda kv: (-kv[1], kv[0])))  # 并列按 ASCII
```

> `Counter.most_common()` 内部是稳定排序，Python 3.7+ 次数相同一定保持
> 字符首次出现的顺序 —— 很多题的答案依赖这个默认行为，别乱改。

### 8. 双字符 / 单词频率

```python
Counter(s[i:i+2] for i in range(len(s)-1)).most_common()      # bigram
Counter(re.findall(r'[A-Za-z]+', text.lower())).most_common()  # 单词
```

### 9. 替换密码：按频率套英文

```python
order = ''.join(c for c, _ in Counter(s).most_common())
table = str.maketrans(order, 'etaoinshrdlucmfwypvbgkjqxz')
print(s.translate(table))
```

### 10. 位置信息（还原顺序 / 验证）

```python
pos = {}
for i, ch in enumerate(s):
    pos.setdefault(ch, []).append(i)
```

### 11. 读文件不崩的三种写法

```python
open(path, 'rb').read().decode('utf-8', errors='ignore')   # 万能，乱码也能统计
open(path, encoding='utf-8', errors='ignore').read()       # 最新写法
open(path, encoding='gbk')                                 # 明确是 GBK 时
```

## 四、五个必踩的坑

1. **正则元字符要转义**：`{ } [ ] ( ) . * + ? ^ $ | \` 都是元字符。
   实测裸写 `'{(.*?)}'` 在 Python 里也能跑（`{` 当字面量），
   但一模一样的思路换成 `'[(.*?)]'` 就变成“字符集”、`'(.*?)'` 内层 `()` 还会多一层捕获组。
   所以**养成全部转义的习惯**：`r'\{(.*?)\}'`、`r'\[(.*?)\]'`。
2. **忘了 `re.S`**：片段跨行时 `.` 默认不匹配换行，`findall` 会漏掉一半。
3. **`print` 出空白字符看不见**：`Counter` 里可能有 `\n`、`\x00`，
   用 `repr(ch)` 或先 `s.split()` 去干净。
4. **找不到花括号还硬跑**：`items` 为空 → 输出空串。加一句
   `assert items, '没匹配到，检查括号/正则'` 立刻定位。
5. **Windows 路径反斜杠**：`'D:\桌面\a.txt'` 里的 `\a` 是转义字符，
   要么用 `r'D:\桌面\a.txt'`，要么用正斜杠 `'D:/桌面/a.txt'`。

## 五、考场 60 秒流程

1. `type 文件名`（或记事本）先看**长什么样**：括号？多行？大小写？有噪声？
2. 抄模板，按第二节的表改 **1 处**（最多 2 处）。
3. 先跑 `print(字符:次数)` 那行 → 看有没有怪字符（`\n`、空格、`?`）。
4. 怪字符就回去改第 ② 步（去空白 / 只留字母数字）。
5. 出结果 → 包 `flag{}` → 交。

## 六、一眼认题型

| 题面长这样 | 大概率是 | 用哪个 |
|---|---|---|
| 一堆 `{x}` 挤在一起 | 频率排序（本手册） | 模板 |
| 一段正常英文长文 | 单词频率 | `word_freq` |
| 一堆 `0101100` | 8 位一组 → chr | 不是词频 |
| 一段乱码字母 | 替换/凯撒 | 频率 + `maketrans` |
| 每个字符重复次数不同 | 频率即顺序 | 模板 |
| 给出的字符集是 `0-9a-f` | hex 编码 | 先 `bytes.fromhex` |
