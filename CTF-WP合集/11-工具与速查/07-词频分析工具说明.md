# 词频分析工具包 · 目录索引

一句话：把文件里 `{...}` 里的字符全抓出来，按出现次数从多到少排序拼成一行 —— 这行通常就是 flag。

## 五、你原来那段代码在干什么（留档）

```python
from collections import Counter
import re
c = ''
with open('D:/桌面/CTF竞赛文件夹/NSS/我flag呢？','r') as f:
    for i in f:
        hh=i                    # ← 坑 1
pattern = re.compile('{(.*?)}', re.S)
items = re.findall(pattern, hh) # ← 坑 2
for i in items:
    c+=i
aa=Counter(c.lower())           # 统计字符出现次数，统一小写
aa = aa.most_common()           # 按次数降序
for i in range(len(aa)):
    print(aa[i][0],end='')      # 按频率顺序把字符打出来
```

它做的事就是经典的 **CTF 词频分析**：题目把 flag 的每个字符藏在 `{}` 里，
出现次数对应字符顺序，出现最多的排第一，依次拼起来就是 flag。

原代码有三个坑：

| # | 位置 | 问题 | 后果 |
|---|------|------|------|
| 1 | `for i in f: hh=i` | 循环变量 `hh` 每轮被覆盖 | 只分析**最后一行**，前面几百行全丢 |
| 2 | `re.findall(pattern, hh)` | 写在循环外，只对 `hh` 匹配 | 同上，匹配范围只有最后一行 |
| 3 | `open(...,'r')` | 不指定 encoding | 中文/GBK 文件在某些环境会 `UnicodeDecodeError` |

另外 `Counter(...).most_common()` 在次数相同时按“首次出现顺序”排，不是随机，
这一点做题时有用（Python 3.7+ 保证字典插入序）。

## 六、`wordfreq.py` 的参数（02 文件夹里的加强版）

| 参数 | 作用 |
|------|------|
| `--all` | 统计整份文件，而不是只抓 `{...}` |
| `--pattern "\[(.*?)\]"` | 自定义抽取正则 |
| `--top N` | 表格只显示前 N 种字符，`0` = 全部 |
| `--no-lower` | 区分大小写 |
| `--keep-space` | 空格/换行也计入统计（默认剔除） |
| `--only 0-9a-f` | 只统计指定字符集 |
| `--no-save` | 不在源文件旁生成 `*-词频.txt` 报告 |

## 七、维护提醒（改这些文件时注意）

1. **bat 必须存成纯 ASCII + CRLF 换行**。
   cmd 按控制台代码页解析批处理字节，文件编码和代码页不一致时会读错位，
   报一堆 `'xxx' 不是内部或外部命令`；LF-only 的 bat 里 `goto`/`pause` 会跑到文件末尾卡死。
   所以中文提示全部放在 `.py` 里（Python 在真实控制台走 `WriteConsoleW`，不受代码页影响）。
2. **不要在 bat 里 `chcp 65001` 之后再 `set /p`**。
   切代码页会让重定向的 stdin 失效，`set /p` 直接读到空值。本工具不碰 `chcp`。
3. **bat 里不要写中文路径**，所以脚本名用 ASCII：`tpl.py`、`wordfreq.py`。
   中文只出现在题目文件名里（那是参数，不参与 bat 解析，安全）。
