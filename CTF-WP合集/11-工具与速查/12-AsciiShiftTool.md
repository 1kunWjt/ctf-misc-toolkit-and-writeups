# ASCII 偏移小工具 v1.0 — 自建工具卡

> 分类：工具 ｜ 用途：凯撒 / ASCII 码偏移类编码题的秒算器
> 位置：`D:\XiaoMibook\CTF学习\AsciiShiftTool\AsciiShiftTool.exe`

## 一、它解决什么问题

Misc / Crypto 里大量出现"每个字符码值 ±n"的题：

- `凯撒密码`：字母表内移位（本工具做的是**码值**偏移，字母题仍以码值偏移为主）
- `ROT47`、`+1/-1` 变体：整段文本每个字符码值 ±1
- 出题人把 flag 每个字符 +13 / -5 这类"手工偏移"

肉眼算 30 个字符会算错，工具 1 秒给出结果并列出逐字符对照。

## 二、功能

| 功能 | 说明 |
|---|---|
| 输入 | 任意字符 / 字符串 |
| 偏移 | 自定义位数，方向可选 **正向 +（码值增大）** / **反向 −（码值减小）** |
| 实时 | 边输入边出结果 |
| 明细 | 下方列出每个字符的 原码 / 新码（DEC + HEX） |
| 回填 | 「结果回填输入」可把输出送回输入框，方便连续偏移（多层偏移题） |
| 码表 | 内置 ASCII 0–127，可勾选扩展区 128–255，双击任意行复制该字符 |

## 三、快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+Alt+M` | **全局**快捷键：任何时候（含最小化）一键调出 ASCII 码表 |
| `F1` | 窗口内打开 ASCII 码表 |
| `Esc` | 关闭码表窗口 |

> 全局快捷键被占用时，程序会自动改用 `Ctrl+Alt+Shift+M` 或 `Ctrl+Alt+F9`，
> 按钮上显示的就是**当前实际生效**的组合。码表窗口只是隐藏、不退出程序。

## 四、计算规则

```
新码值 = 原码值 + 偏移位数      （方向为「反向」时按减计算）
```

- 结果按原字符输出；不可打印字符对照下方「码值 HEX」与明细表看
- 码值越界（< 0 或 > 65535）时该字符显示 `?`，明细表中标红提示"越界"

## 五、赛场判断

```
看到一串"看起来像英文但每个字母都错一位"的文本
 ├─ 先试 -1 / +1（最常见的 ROT1 变体）
 ├─ 再试 ±13（ROT13）
 ├─ 还是乱码 → 可能同时混了大小写/数字，逐字符对码值表找规律
 └─ 多层偏移（先 +5 再 -2）→ 用「结果回填输入」连续跑
```

## 六、源码与重编译

`AsciiShiftTool.cs`（36 KB，C# WinForms）是完整源码，`build.bat` 用 csc 直接编译：

```bat
csc /target:winexe /win32icon:app.ico /out:AsciiShiftTool.exe AsciiShiftTool.cs
```

改快捷键、加"只对字母偏移"的选项，都在这份源码里改。
