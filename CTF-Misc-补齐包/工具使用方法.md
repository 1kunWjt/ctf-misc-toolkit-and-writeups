# CTF 杂项工具包 · 使用手册

> 双击 **`启动菜单.bat`** 就能用。这份文档解释每工具怎么用、以前为什么黑屏、报错怎么处理。

---

## 0. 三十秒上手

三种用法，任选：

| 方式 | 适合 | 怎么做 |
| --- | --- | --- |
| **菜单**（推荐） | 不知道用哪个工具、忘了参数 | 双击 `启动菜单.bat` → 输入编号 → 按提示拖文件进去 |
| **拖拽** | 已经知道用哪个工具 | 把文件**直接拖到对应的 `.bat` 图标上**松手 |
| **命令行** | 要串命令、批量跑 | 双击 `环境变量.bat` 开一个配好环境的 cmd，然后敲 `vol`/`zsteg`/`binwalk` 等 |

菜单里输编号回车即可；也可以直接输工具名（如 `zsteg`），输 `0` 退出。

## 1. 以前双击为什么是「黑屏」——原因与修复

「黑屏」其实是**黑色窗口一闪就关**，什么都来不及看。逐条对照本版的修复：

| 原来的问题 | 现象 | 本版处理 |
| --- | --- | --- |
| 每个 bat 都只有一行命令，**结尾没有 `pause`** | 命令跑完/报错，窗口立刻关 | 全部加 `pause`；从菜单启动时不再重复暂停 |
| `TweakPNG.bat` 写的是 `%~dp0tweakpng.exe`，实际文件在 `x64\`、`x86\` 子目录 | 弹「Windows 找不到文件」或者毫无反应 | 自动探测 `x64\tweakpng.exe` → 退回 `x86\` |
| Python 工具在 GBK 控制台下打印中文 | 满屏「鍥㈤槦」乱码 | bat 里加 `chcp 65001` + `PYTHONUTF8=1` + `PYTHONIOENCODING=utf-8` |
| 命令行工具本来就要参数，双击 = 没给参数 | 打印一大段帮助后关窗口，看着像崩了 | 现在先显示**中文用法卡片**，再调工具自带 `--help`，最后暂停 |
| `blindwatermark.bat` 帮助里的 `<image>` | cmd 把 `<` `>` 当重定向，报 `< was unexpected at this time` | 生成器统一转义 `^<` `^>` `^\|` `^&` |
| **zsteg 在含中文的路径下直接崩溃** | `Encoding::CompatibilityError: incompatible character encodings` | 已给 `file_cmd.rb` 打补丁（两边强制 binary） |
| ciphey 首次运行会进交互式配置向导 | 一直停在那里问问题，像卡死 | 文档里说明（见 §2.3），回车跳过一次即可 |
| 找不到 python / java 时 | 一行英文报错后秒关 | 现在给中文提示 + 安装建议，并暂停 |

> 想改工具行为：**改 `_scripts/gen_launchers.py` 后重跑**，别直接改 bat——bat 是脚本生成的，重跑会覆盖。

## 2. 每个工具怎么用

### 2.1 隐写（01-隐写工具）

#### zsteg —— PNG/BMP 隐写全量扫描
- **用途**：把 PNG/BMP 的每个位平面、每种通道组合、每像素各种位宽全扫一遍，找藏着的字符串/文件。CTF 图片题第一枪。
- **启动**：拖图片到 `01-隐写工具\zsteg\zsteg.bat`；或菜单选 1。
- **常用**：
  ```bat
  zsteg.bat -a 1.png                       :: 全量扫描（先跑这个）
  zsteg.bat -E "b1,rgb,lsb,xy" 1.png       :: 只提取某组合的隐藏数据
  zsteg.bat -o xy 1.png                    :: 换像素遍历顺序
  ```
- **看结果**：每行形如 `b1,rgb,lsb,xy .. text: "flag{...}"`，`..` 后面就是提取到的东西；`file: PNG image` 表示嵌了文件。
- **踩坑**：开头那句 `Failed to create a system wide 'gemrc' file` 是正常的，忽略。

#### StegSolve —— 通道/位平面肉眼找
- **用途**：Java 图形工具，切 R/G/B/A、位平面、帧，靠眼睛找异样（最常见：某个位平面出现文字）。
- **启动**：`StegSolve.bat`；也可以把图拖到 bat 上预加载。
- **怎么用**：图拖进窗口 → 底部 `Frame Browser` 左右箭头切通道/位平面 → `Analyse`→`Data Extract` 按通道+位提取。
- **踩坑**：窗口没出现说明 Java 有问题，在本目录开 cmd 跑 `java -jar StegSolve-1.4.jar` 看真实报错。

#### TweakPNG —— PNG chunk 级查看/修改/重算 CRC
- **用途**：看/改 `IHDR`、`tEXt`、`zTXt`、`iTXt` 等 chunk，改完重算 CRC。假 CRC、文本藏数据、IHDR 造假都靠它。
- **启动**：`TweakPNG.bat`（自动定位 x64/x86 版 exe），或把 png 拖到 bat 上。
- **怎么用**：打开 png → 左列 chunk 列表逐个看 `Value` 列 → 双击可改 → 改完 `File`→`Save` 会让它重算 CRC。
- **踩坑**：改 CR**C/IDAT** 不改内容会直接让图打不开；先复制一份再改。

#### BlindWaterMark —— 盲水印编/解
- **用途**：给图片打不可见水印，或从图片里还原水印。图片隐写常见套路。
- **启动**：`blindwatermark.bat`；或菜单选 4（会提示你输参数）。
- **命令**（两步，参数都是三个文件）：
  ```bat
  blindwatermark.bat encode hui.png wm.png out.png             :: 打水印
  blindwatermark.bat decode hui.png out.png wm_from_out.png    :: 还原水印
  blindwatermark.bat encode hui.png wm.png out.png --alpha 3.0 --seed 20160930
  ```
- **踩坑**：decode 需要**原图和含水印图两张**；只有一张时，用同尺寸纯图/截图当参照多试几次。

#### QrazyBox —— 离线二维码分析
- **用途**：残缺/被遮挡二维码的重建、掩码与格式位分析。离线，断网可用。
- **启动**：`QrazyBox.bat`（用默认浏览器打开本地页面）。
- **怎么用**：载入二维码截图 → 按提示标出三个定位角 → 它补全并解码。
- **踩坑**：截图尽量正、别裁掉三个角；分辨率太低先放大。

### 2.2 取证（02-取证工具）

#### Volatility 3 —— 内存取证主力
- **用途**：内存镜像里翻进程、网络连接、命令行、注册表、文件。
- **启动**：拖镜像到 `Volatility3\vol.bat`（默认跑 `windows.info`）；或菜单选 6（可改插件）。
- **常用**：
  ```bat
  vol.bat -f mem.raw windows.info        :: 确认镜像类型（先跑）
  vol.bat -f mem.raw windows.pslist      :: 进程树
  vol.bat -f mem.raw windows.cmdline     :: 进程命令行（找 flag 最常用）
  vol.bat -f mem.raw windows.netscan     :: 网络连接
  vol.bat -f mem.raw windows.filescan | findstr flag
  vol.bat -f mem.raw windows.registry.printkey --key "ControlSet001\Control\ComputerName"
  ```
- **踩坑**：首次跑某插件会建符号缓存（慢，几十秒到几分钟）；缓存放在 `Volatility3\cache`，不污染系统。慢插件：`malfind`、`handles`。

#### MemProcFS —— 把内存镜像挂成盘
- **用途**：不背插件名，直接把内存镜像挂成一个虚拟文件系统，用资源管理器翻 `files/`、`registry/`、`pid/`、`name/`。
- **启动**：拖镜像到 `MemProcFS.bat` → 自动挂到本目录 `mnt\`。
- **常用**：
  ```bat
  MemProcFS.bat -device mem.raw -mount D:\mnt
  MemProcFS.bat -device mem.raw -mount mnt -forensic 1
  ```
- **踩坑**：挂载时窗口要一直开着，`Ctrl+C` 结束；驱动已随包提供，个别机器需要管理员权限。

#### LovelyMem —— 内存取证一体化 GUI
- **用途**：内置 Volatility2，点鼠标就能出进程/网络/注册表/浏览器记录，适合快速过一遍。
- **启动**：双击 `Lovelymem-V2-2.5.0-windows-x64.exe`（菜单选 8 也行）。
- **踩坑**：结果要和 Volatility 3 复核；大镜像吃内存。

#### ZipCenOp —— ZIP 伪加密
- **用途**：压缩包的加密位被置 1（看起来加密）但其实没密码，一键去掉。
- **启动**：拖 zip 到 `ZipCenOp.bat` → 自动 `r`；或菜单选 9。
- **常用**：
  ```bat
  ZipCenOp.bat r file.zip    :: 去掉伪加密（会直接改 zip，先备份）
  ZipCenOp.bat e file.zip    :: 反向：加伪加密（出题用）
  ```
- **踩坑**：`r` 是原地改文件；判据是解压时不弹密码框或密码随便输也错。

#### Hashcat —— 哈希爆破
- **用途**：字典/掩码爆破各种哈希，配 rockyou.txt。
- **启动**：`hashcat.bat`；或菜单选 10（会提示输参数）。
- **常用**：
  ```bat
  hashcat.bat -m 0 -a 0 hashes.txt rockyou.txt     :: MD5 + 字典
  hashcat.bat -m 0 hashes.txt --show               :: 看已爆破结果
  hashcat.bat -m 17200 hashes.txt rockyou.txt      :: ZIP 伪加密
  hashcat.bat -m 1000 hashes.txt rockyou.txt       :: Windows NTLM
  hashcat.bat -b                                   :: 先测本机速度
  ```
- **踩坑**：运行中按 `s` 看进度、`p` 暂停、`q` 退出；`-m` 是哈希类型，查 <https://hashcat.net/wiki/doku.php?id=example_hashes>。

### 2.3 MISC 解题（03-MISC解题）

#### Ciphey —— 自动识别并解码
- **用途**：给它一段密文，自动猜 Base/ROT/摩斯/凯撒/Atbash… 并解出明文。
- **启动**：`ciphey.bat`；或菜单选 11（提示输入文本）。
- **常用**：
  ```bat
  ciphey.bat aGVsbG8gd29ybGQ=
  ciphey.bat -t "Uryyb Jbeyq" -v -v
  ciphey.bat -t "..." -c 30
  ```
- **首次运行**：会问「要不要教程」「配色方案」等，一路回车跳过即可，之后不再问。
- **踩坑**：输入是**文本不是文件**；二进制先 `strings` 再取可疑片段。若报 `Could not create ciphey directory: PermissionDenied`，说明当前账户不能写自己的用户目录（受限账户/AppData 被管控），改用 CTFCrackTools 或 CyberChef。

#### CRC32-Tools —— ZIP CRC 碰撞
- **用途**：zip 里小文件已知 CRC32 和长度时，反推明文（1–4 字节碰撞）。
- **启动**：拖 zip 到 `CRC32-Tools.bat`（默认 `-z` 列 CRC）；或菜单选 12。
- **常用**：
  ```bat
  CRC32-Tools.bat -z file.zip    :: 列出每个条目的 CRC32
  CRC32-Tools.bat -1 file.zip    :: 1 字节碰撞
  CRC32-Tools.bat -2 file.zip    :: 2 字节
  CRC32-Tools.bat -3 file.zip    :: 3 字节
  CRC32-Tools.bat -4 file.zip    :: 4 字节
  ```

#### PNG 尺寸修复（Deformed-Image-Restorer）—— IHDR 宽高爆破
- **用途**：PNG 宽高被改坏（图只显示上半截 / CRC 报错）时自动爆破正确尺寸并导出修复图。
- **启动**：拖残缺 png 到 `fixpng.bat`（自动 `-i`）；或菜单选 13。
- **常用**：
  ```bat
  fixpng.bat -i broken.png            :: 自动爆破宽高
  fixpng.bat -r 1200x800 broken.png   :: 已知尺寸直接修
  ```
- **踩坑**：修复图输出在原图同目录。

#### Typhon —— pyjail 逃逸
- **用途**：Python 沙箱逃逸题，自动搜索可用 payload。
- **启动**：`typhon.bat webui`（菜单选 14 后输 `webui`）→ 浏览器里操作。
- **踩坑**：把题目 jail 源码 / 黑名单粘进 Web UI 再搜；直接跑 `typhon.bat --help` 看全部参数。

#### FileReverse-Tools —— 文件反转/倒置/hex
- **用途**：双字节倒置、十六进制倒置、hex 导出/还原，二进制被「倒着存」的题常用。
- **启动**：拖文件到 `FileReverse-Tools.bat`（默认 `-hh` 导出 hex）；GUI 版是 `FileReverse-Tools_Win_x64_1.02.exe`。
- **常用**：
  ```bat
  FileReverse-Tools.bat -hh file.bin    :: 文件 → 16 进制文本
  FileReverse-Tools.bat -uh file.txt    :: 16 进制文本 → 文件
  FileReverse-Tools.bat -i  file.bin    :: 按双字节读并倒置
  FileReverse-Tools.bat -r  file.bin    :: 十六进制倒置
  FileReverse-Tools.bat -re file.bin    :: 双字节反转
  FileReverse-Tools.bat -a  file.bin    :: 导出 hex 数组
  FileReverse-Tools.bat -b  file.txt    :: base64 文本 → 文件
  ```

#### CTFCrackTools-X —— MISC 综合 GUI
- **用途**：编码、现代密码（RSA 小工具）、杂项一堆模块，图形界面。
- **启动**：双击 `ctfcracktools-x-0.1.2-windows-x64.exe`（菜单选 16）。

### 2.4 文件与十六进制（04-文件与十六进制）

#### binwalk —— 文件签名扫描
- **用途**：一个文件里藏了别的文件（jpg 后接 zip、固件里的 squashfs），用它定位偏移。
- **启动**：拖文件到 `binwalk.bat`（直接签名扫描）；或菜单选 17。
- **常用**：
  ```bat
  binwalk.bat file.bin               :: 签名扫描
  binwalk.bat -A file.bin            :: 指令特征扫描
  binwalk.bat -R "\x89PNG" file.bin  :: 按原始字节搜
  binwalk.bat -e file.bin            :: 尝试解包（Windows 支持有限）
  ```
- **踩坑**：拿到 offset 后建议用 **Bandizip / 010 Editor** 手动切（`-e` 依赖 7z 等外部工具）。

### 2.5 密码学库（05-密码学）

#### 密码学库环境 —— 开一个带 pycryptodome/gmpy2/z3 的 Python
- **用途**：直接写 RSA / 大整数 / 约束求解脚本，不用折腾 pip。
- **启动**：`密码学库环境.bat`（菜单选 18）→ 打开一个已配好 `PYTHONPATH` 的 cmd。
- **验证**：
  ```bat
  python -c "import Crypto,gmpy2,z3;print(Crypto.__version__,gmpy2.version(),z3.get_version_string())"
  python -c "from Crypto.Util.number import *;print(long_to_bytes(0x666c6167))"
  ```
- **踩坑**：这些库在 `05-密码学\*\lib`，通过 `PYTHONPATH` 挂载，不影响系统 Python；关窗口即失效，下次重新双击。

### 2.6 其他

- **`环境变量.bat`**（包根目录）：开一个已把 `ruby`（zsteg 用）和三个密码学库加进 PATH/PYTHONPATH 的 cmd，适合手动串命令。
- **`启动菜单.bat`**：交互菜单，含「检查环境」项（看 python/java/node/ruby 是否就绪）。

## 3. 典型题目流程（速查）

**图片隐写（最常考）**
```
file 看类型 → binwalk 看有没有附加数据
→ zsteg -a 全扫 → StegSolve 切通道/位平面看
→ TweakPNG 看 tEXt/IHDR → 尺寸坏了用 fixpng -i
→ 有二维码：QrazyBox / 图片\扫码
```

**压缩包**
```
zipinfo / 010 看加密位 → ZipCenOp r 试伪加密
→ CRC32-Tools -z 看 CRC → 小文件用 -1..-4 碰撞
→ 有已知明文走 bkcrack → 否则 hashcat -m 17200 爆
```

**内存取证**
```
vol -f mem.raw windows.info        （确认镜像）
→ windows.pslist / netscan / cmdline
→ windows.filescan | findstr flag
→ 细节不够就拖进 MemProcFS 挂盘翻 files/ registry/
```

**pyjail**
```
typhon.bat webui → 粘源码/黑名单 → 搜 payload
```

**编码/古典密码**
```
CyberChef（Magic）→ Ciphey 自动解 → CTFCrackTools 补充
→ 维吉尼亚/古典多表替换：用 **CTF-Toolkit** 里的「维吉尼亚自动破解」（自动判长度 + crib）
```

## 4. 报错对照表

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `'python' 不是内部或外部命令` | Python 不在 PATH | 装 Python 3.10+，安装时勾「Add python.exe to PATH」 |
| `'java' 不是内部或外部命令` | 没有 JRE | 装 Java 8+（<https://adoptium.net/>），或 `winget install EclipseAdoptium.Temurin.17.JRE` |
| `Failed to create a system wide 'gemrc' file` | zsteg 想写 `C:\ProgramData` 被拒 | 忽略，不影响结果 |
| `incompatible character encodings: UTF-8 and BINARY` | zsteg 旧 bug（中文路径触发） | 本版已修；若再遇到，把文件复制到纯英文路径再跑 |
| `< was unexpected at this time` | bat 里有未转义的 `<` | 本版已修（生成器统一转义） |
| `Could not create ciphey directory: PermissionDenied` | 用户目录不可写 | 换 CTFCrackTools / CyberChef，或以有权限的账户运行 |
| ciphey 一直停在提问 | 首次运行配置向导 | 一路回车跳过，之后正常 |
| Volatility 某个插件特别慢 | 首次建符号缓存 | 等它；缓存会留在 `Volatility3\cache` |
| MemProcFS 挂载失败 | 缺驱动权限 | 用管理员身份运行一次 |
| 双击 bat 一闪而过 | 老问题 | 本版所有 bat 都会停住；从菜单启动更稳 |

## 5. 维护：bat 是生成的，别直接改

```
_scripts/gen_launchers.py     ← 所有 .bat 的唯一来源（改这里）
_menu.ps1                     ← 交互菜单（可直接改，改完存盘生效）
启动菜单.bat                  ← 菜单入口（调用 _menu.ps1）
```

改完生成器后执行：

```bat
python _scripts\gen_launchers.py
```

会重新生成全部 18 个 bat（`chcp`/转义/pause/依赖检查都在生成器里统一处理）。

快速自检（不弹菜单，只渲染一次）：

```bat
启动菜单.bat -selftest
```
